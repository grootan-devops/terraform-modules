## What each column means

- **Controls**: controls listed for the standard in the AWS user guide on the catalog date (2026-11-18).
- **Apply to resources this library creates**: controls whose resource type matches a resource type that a module under `modules/aws/` creates. The other controls cover services this library does not manage, or account-level settings.
- **Account-level controls**: evaluated against the account (`AWS::::Account`), for example root user MFA, the organization trail, Config recording, GuardDuty. These are met by the organization and security modules, or need live-account evidence.
- **Controls with an AWS Config rule**: these need AWS Config recording for the resource type in every account and Region, which [`security/config`](../../modules/aws/security/config) provides. Controls without a rule are evaluated by Security Hub directly or are periodic account checks.
